# 行为验收基线

本目录放**行为基线**：一套固定场景 + 固定假时钟，记录若干观测值，任何实现都必须逐项对上。

- `observations.md`：观测项清单（**规格**，含期望值与夹具要求）。
- `fixtures/`：夹具——`tiles.png`（自绘色块，由 `make_tiles.py` 生成）+ `level.tmx`（自写地图）。
- `run.py`：在新引擎上跑一遍并输出 JSON（M1 之后实现，从规格写）。
- `baseline.json`：冻结的基线（首次实现跑通后生成）。

比较规则：浮点 `abs_tol=1e-3`；布尔 / 整数 / 字符串 / 像素哈希完全一致。
行为确实要变时，重新生成基线并在提交信息里说明原因。
