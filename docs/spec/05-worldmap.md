# 05 瓦片地图（TMX）

> 实现依据。地图用 Tiled 编辑，运行期用 pytmx 解析。

## 1. 载入

```
m = TiledMap("地图.tmx")
```

- 解析后立刻确定：地图像素尺寸（`宽 × 高`）、图块尺寸、所有图层、对象层里的对象。
- **坐标换算只做一次**：把 Tiled 的"左上原点"坐标换算成引擎的"居中、y 向上"坐标；
  反复读取对象坐标不得再次叠加偏移（旧版踩过这个坑：连续两次 `objects` 让坐标漂移）。
- 载入失败（文件不存在 / 路径不是 TMX）→ 中英双语可读错误 + 提示检查路径。
- 图块需要 pygame 的显示表面：**还没 `setup()` 就载入地图**时，要给出「先调用 setup()」的
  中英双语提示，而不是把底层 pytmx / pygame 的报错直接抛给学生。

## 2. 渲染

- `m.render(表面)` 把地图的全部图块图层按顺序画到给定表面。
- 也支持把整张地图作为一个**视觉组件**挂到实体上（见 `04` 的整图策略），
  这样地图能像普通对象一样缩放/移动/销毁。
- `bgpic(地图)` = 把地图作为背景铺开，并把相机尺寸设为地图大小，返回该对象。
  地图可以给 **`TiledMap` 对象**，也可以直接给 **`.tmx` 路径**（按扩展名识别，学生更常这么写）。

## 3. 对象层 → 实体

### 3.1 查询原始对象

- `m.objects`：对象层里的对象列表（含名字、坐标、大小、点集、自定义属性、原始 TMX 对象）。
  结果应当**幂等**：多次读取返回同样的坐标。
- `m.get_objects(名字=None)`：按名字过滤；不传名字返回全部。

### 3.2 创建实体

```
m.create_objects(name=None, body_type="STATIC", sensor=False, images=None, world=None)
```

| 参数 | 说明 |
|---|---|
| `name` | 只创建该名字的对象；留空表示全部 |
| `body_type` | 生成的刚体类型（默认静态，适合地形/触发器） |
| `sensor` | 是否只做触发 |
| `images` | `{对象名: 图片}` 映射，可给对象加贴图 |
| `world` | 目标场景 |

生成的实体必须：

1. **每个对象一个**（不是把整层合成一个大刚体），名字、尺寸、位置都对；
2. 矩形/多边形对象 → 多边形刚体；几何落在**换算后的**坐标上（点查询能命中）；
3. **图块对象（带 `gid`）自动带贴图**，位置与解析后的对象坐标一致；
4. 自定义属性与原始 TMX 对象可读（`properties` / `tmx_object`）；
5. 与"整张地图当一个瓦片刚体组"是**两条不同路径**，不要互相污染：
   `create_objects` 出来的实体没有瓦片刚体组。

### 3.3 整张地图当碰撞体

- `Entity(size=[对象…])`（扁平对象列表）→ 瓦片刚体组：每块瓦片各自成为一个形状，
  按各自相对偏移摆放（见 `03` §4）。

## 4. 坐标换算约定

```
对象宽高 (w, h)，地图像素尺寸 (W, H)，Tiled 坐标 (x, y)：
  x' = x - (W - w) / 2
  y' = (H - h) / 2 - y
```

- 图块对象的 `gid` 由 pytmx 解析；只要能在图集里取到图块就自动加贴图。
- 自定义属性（Tiled 里填的 `properties`）要原样保留，键名保持 Tiled 里的写法。

## 5. 验收点

- `objects` / `get_objects()` 多次读取坐标不变。
- 用验收夹具地图（`acceptance/fixtures/level.tmx`）创建实体后逐项对上
  `acceptance/observations.md` 里的 `tiled_objects`（6 个对象的坐标与"有刚体/无瓦片组/有贴图"）。
- 每个对象的几何中心点查询命中所属对象。
- 图块对象（`coin_a`/`coin_b`）带贴图且尺寸为图块尺寸。
- `get_objects("不存在的名字")` 返回空列表（不报错）。
