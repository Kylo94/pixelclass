# 03 物理与碰撞

> 实现依据。数值单位：像素、秒、度（对外）/ 弧度（pymunk 内部）。

## 1. 刚体类型（课堂上怎么说）

| 类型 | 会受重力/力 | 会被别的物体推动 | 会挡住别人 | 典型用途 |
|---|---|---|---|---|
| 静态 STATIC | 否 | 否 | 是 | 地面、墙 |
| 动态 DYNAMIC | 是 | 是 | 是 | 角色、箱子 |
| 运动学 KINEMATIC | 否 | 否 | 是 | 平台、传感器 |

- `sensor=True`：形状只"报告接触"，不产生阻挡（穿透型触发器）。
- 静态刚体不参与"最快速度"统计（见 `01` 的子步规则）。

## 2. 形状与构造

```
Rigid(body_type, shape="CIRCLE"|"BOX"|"POLY", size=..., sensor=False, world=None)
```

| 形状 | `size` | 说明 |
|---|---|---|
| `CIRCLE` | `int` 半径 | 圆形 |
| `BOX` | `(w, h)` | 矩形 |
| `POLY` | `[[x, y], …]` | 多边形（顶点） |

- 面积/质量：默认按几何自动计算；`mass` 可读写覆盖。
- 常见属性：`velocity`、`angular_velocity`、`mass`、`elasticity`（0~1）、`friction`（0~1）、
  `sensor`、`shape`（底层形状，供进阶用法）。

## 3. 位置 / 角度写入与"宽相重排"

物理引擎维护形状的位置缓存（宽相）。**位置没变就不要重排**：

- 写位置时若与刚体当前位置相同 → 直接返回，不触碰空间；
- 写角度时若与刚体当前角度相同 → 直接返回，不触碰空间；
- 物理每帧把刚体状态回写到显示层时，走**只改显示缓存**的路径（`sync_pos` / `sync_rot`），
  **绝不反向写回刚体**。

> 这些规则来自实测：每帧无意义的重排会让帧率随精灵数量下降，是课堂演示卡顿的主因之一。

## 4. 瓦片刚体组

用于"用整张瓦片地图当碰撞体"（课堂上的地形、平台地图）。

- 输入：一组至少含 `points` 的对象，每个对象可选 `x` / `y` 作为**相对组原点的偏移**。
- 每块瓦片是一个独立形状，但共享一个组位置；**组移动时每块瓦片都要按自己的偏移重新摆放**。
- 组的 `pos` 读写与实体的 `pos` 同步（实体移动整组跟着走）。
- 邻居连接：把整张地图设成动态（少见）时，按**上下左右相邻**给瓦片之间加关节，
  使地图成为一整块而不是散落的碎片；静态地图**不创建任何关节**。
- 关节数量必须远小于"两两连接"（按邻居关系连）+1。

## 5. 碰撞检测的三条路径（优先级从高到低）

```
单个刚体（圆 / 矩形 / 多边形）  >  瓦片刚体组  >  贴图 mask
```

- 实体有点查询接口：`collide(坐标)` → 该点是否落在对象几何内（布尔）；
- 实体间碰撞：`collide(另一个对象)` → 两个对象是否接触（布尔）；
- 只有贴图、没有刚体时，用贴图的 alpha mask 做像素级判定；
- 几何判定必须覆盖**四种组合**：圆-圆、圆-盒、盒-盒、以及多边形参与的情况；
  点查询对贴图对象要检查**中心点与四角**（避免"明明在图里却判定没碰到"）。
- 分离：`separate(另一个对象)` 把两个互相重叠的对象沿最小方向推开；
  重叠很浅或完全重合时也要有确定的行为（不能随机抖动）。

## 6. 约束（关节）

| 名字 | 物理含义 | 语义 |
|---|---|---|
| 销钉 `pin(a, b)` | pymunk 的销钉关节 | 保持创建时的距离（刚性杆） |
| 弹簧 `spring(a, b, …)` | 阻尼弹簧 | 距离被拉回自然长度（默认自然长度 = 创建时距离） |

- 参数接受**实体**或**裸刚体**两种；判定用类型检查（`isinstance`），不要用"有没有某个属性"猜测。
- 关节加进参数对象所属场景的物理空间；无刚体的实体要给出中英双语 `TypeError`，并提示怎么改。
- 关节也应当能被查询/列举（用于测试与调试）。

## 7. 不变量

1. 静止物体不产生额外开销：位置/角度没变时不做任何空间重排。
2. 静态地图不创建关节。
3. 子步只在"最快物体一步位移超过阈值"时启用（见 `01` §3.2）。
4. 碰撞判定与点查询全部使用**数学坐标**（原点在窗口中心、y 向上）。

## 8. 验收点

- 自由落体：同一场景下 30 帧后的位置与速度与基线一致（重力 -1200，初速 (30, 0)）。
- 点查询：命中几何中心为真、远点为假；贴图对象用中心 + 四角判定。
- 对象碰撞：两个重叠对象为真、相距很远为假。
- 分离：重叠的两个对象被推开到不重叠（结果确定，可复现）。
- 瓦片组：N 块瓦片的组里每块都落在自己的坐标上（点查询能命中各自中心）。
- 邻居连接：25 块瓦片的网格地图的关节数远小于两两连接；远处孤立瓦片不被连入。
- 约束：销钉连接的两物体距离保持不变；弹簧把距离拉向自然长度。
- 防穿透：2400 px/s 的子弹打 8 px 厚的墙不穿透；关闭子步（阈值 0）时**应当**穿透
  （用来证明子步就是修复手段）。
