# 07 报错、字体、文本与工具

> 实现依据。这一章面向"课堂上最容易卡住学生的地方"。

## 1. 中英双语报错

- 框架自身抛出的错误一律**中英双语**：中文在前、英文在后，保留原始异常类型。
- 示例（忘记初始化）：

  ```
  RuntimeError: 还没有初始化窗口：请先调用 setup(800, 600)
                setup() first: no window/space yet.
  ```

- 覆盖面（至少）：未初始化就用、对象没有刚体、对象没有贴图、资源路径错、
  动画状态名不存在、约束参数没有刚体、地图文件解析失败、pymunk 版本差异。

## 2. 全局异常钩子

| 接口 | 语义 |
|---|---|
| `install_error_help()` | 安装 `sys.excepthook`：未捕获异常时先打印中文解释，再打印原始 traceback |
| `uninstall_error_help()` | 还原默认钩子 |
| `set_error_help(布尔)` / `is_error_help_enabled()` | 开关与查询 |
| `explain_exception(异常对象)` | 返回中文说明（供 `try/except` 里自己调用） |

- 环境变量 `PIXELCLASS_ERROR_HELP=0` 可关闭（**用本项目自己的前缀**，不复用旧项目变量名）。
- **默认开启**：`import pixelclass` 时就安装钩子（学生不需要额外写一行）；`uninstall` 要能还原
  安装前的钩子（可能是别人的钩子，不能直接设成默认钩子）。
- 钩子必须**不动**原异常类型与原始信息：只是"多印一段中文解释"。

### 2.1 规则匹配要克制

- 规则按"异常消息里的特征串"匹配时要**避免过宽**：例如不能把任何 `NoneType` 的
  `AttributeError` 都判成"忘了 setup()"，否则会误导（旧版踩过）。
- 匹配不到规则时什么都不加，直接走默认行为。

## 3. 中文字体

- 查找顺序（第一个可用即止）：
  1. 包内自带字体目录；
  2. 系统常见中文字体（按平台列出候选路径：Windows / macOS / Linux 各若干）；
  3. pygame 默认字体（此时中文可能显示为方块——给**一次**提示，不中断运行）。
- 允许显式指定字体路径（例如 `obj.font = r"C:\Windows\Fonts\msyh.ttc"`）。
- 包内**不打包**任何受版权保护的商业字体（微软 / 中易等）；找不到就用系统或默认字体。

## 4. 文本与对话框

| 类 | 语义 |
|---|---|
| `TextBox` | 屏幕文字：位置、字号、颜色、背景；`write(文字)` 更新内容；每帧更新不闪烁 |
| `DialogBox` | 跟随某个对象的对话框：根据对象在屏幕中的象限自动选择朝上的角；`say(文字)` 显示、`hide()` 隐藏 |

- 文本对象也是实体：可以 `goto()`、`color`、`visible`、`kill()`。
- 对话框在目标被 `kill()` 后不得报错。

## 5. 场景级工具

| 接口 | 语义 |
|---|---|
| `title(文字)` | 设置窗口标题 |
| `save_screen(路径)` | 保存当前画面为图片（用于截图留念/交作业） |
| `debug(布尔)` | 调试绘制：把场景里所有刚体（含瓦片组）的轮廓画出来 |
| `tracer(布尔)` | 帧率跟踪：开启后约每秒打印一次 FPS |
| `speed(值)` | 限制每帧最大位移步数（"慢动作"，方便观察） |
| `draw_line(起, 止, 颜色, 宽)` | 画一条线，下一帧自动清除 |
| `set_gravity(x, y)` | 设置该场景重力 |
| `random_pos(margin=0, world=None)` | 在**当前可视区域**内取随机坐标（撒道具/出题用；`margin` 是离边缘的留白） |
| `sign(x)` | 符号函数（-1 / 0 / 1） |
| `set_depth(层)` | 返回资源目录路径；**不得改变进程工作目录**（旧版会 `chdir`，现在是返回路径 + 弃用警告） |
| `Cartesian2pygame` / `pygame2Cartesian` | 坐标换算（见 `01` §1） |
| `vec` / `to_cp` | 向量构造与"转成 pymunk 可用类型"（`pygame.Vector2` 直接传给 pymunk 会报类型错，必须转换） |

## 6. 验收点

- 忘记 `setup()` 就创建对象 → 报错信息含中文与英文，且指明怎么改。
- `install_error_help()` 后未捕获异常会多打印一段中文；`uninstall` 后恢复。
- `explain_exception` 对"没传 size 的角色"给出与"没 setup"不同的解释（不误判）。
- 找不到中文字体时不崩溃（给一次提示）。
- `TextBox` / `DialogBox` 能创建、更新、跟随、销毁。
- `set_depth` 调用前后进程工作目录不变，且有弃用警告。
- `to_cp(vec(1, 2))` 可被 pymunk 接受（不再出现 ctype 类型错误）。
