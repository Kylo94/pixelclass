# 04 视觉与动画

> 实现依据。数值单位：像素、度、秒。

## 1. 视觉组件（Visual）

一个视觉组件 = 一张（或一组）图 + 绘制状态。它自己不知道实体逻辑，只负责"这一帧该画什么、画在哪"。

### 1.1 四种绘制来源（构造时按输入类型决定）

| 输入 | 策略 | 说明 |
|---|---|---|
| 路径字符串 / `pygame.Surface` | 单图 | 永远画同一张 |
| 路径列表 | 帧序列 | 按 `frame` 索引取图；`dt` 控制每帧停留秒数 |
| `{"状态名": [帧…]}` | 状态机 | 每个状态是一组帧；可设下一状态与首末回调 |
| 瓦片地图对象 | 整图策略 | 把整张地图当一张大图绘制 |

- 判定顺序：先看是不是地图对象 → 再看是不是字典 → 再看是不是序列 → 否则按单图处理。
- 图集（多帧拼在一张图上）用 `SpriteSheet` 描述：提供每帧的子矩形。

### 1.2 绘制状态

| 属性 | 语义 |
|---|---|
| `pos` / `rot` / `scl` | 由实体提供（视觉组件只是读它） |
| `visible` | 为假时既不绘制也不参与"鼠标悬停"判定 |
| `red/green/blue/alpha` | 着色与透明度；改动后标记"需要重绘" |
| `fliped` / `is_flip_h` / `is_flip_v` | 翻转 |
| `layer` | 绘制层级（数值大的画在上面） |
| `modified` / `scaled` / `rotated` | **重绘标记**：只在需要时重算变换后的图像 |

### 1.3 变换与缓存（性能关键）

- 贴图的旋转/缩放/着色都是**有成本**的操作：结果必须缓存，只有在对应标记为真时重算，
  算完把标记复位。
- 只改位置（不转不缩放不染色）时，**不得**触发图像重算——只更新绘制矩形。
- 变换缓存的键必须能区分"缩放 + 旋转 + 翻转 + 尺寸"的组合；标记复位后重复 `update()` 不再重算。

## 2. 动画

### 2.1 帧序列

- `frame` 读写当前帧索引；`dt` 读写每帧停留时间（秒，默认约 `1/12`）。
- `set_dt(秒)`：同样是改每帧停留时间（帧序列不写动画名字）。
- `dt` / `set_dt` 的值必须是**正数秒**：非数字或 ≤ 0 一律给可读的中英双语错误——
  停留时间为 0 会让帧推进变成死循环，必须在入口拦住；想停住动画用 §2.4 的 `pause_anim()`。
- `update()` 按经过时间推进帧；超出末尾后回到 0（循环）。
- 帧数只有 1 时不做任何推进。

### 2.2 状态机

- `state` 读当前状态名；**写状态在下一帧生效**（避免在遍历中改集合）。
- `set_next_state(状态[, 条件函数])`：满足条件时切换（条件默认"当前状态播放完"）。
- `set_start_func(函数)` / `set_end_func(函数)`：进入/离开状态时回调。
- `set_dt(状态名, 秒)`：只改**这一个状态**的每帧停留时间（各状态可以不一样快，
  例如 `idle` 慢、`run` 快）；只写一个数值则改所有状态。状态名不存在 → 可读错误并列出可用状态。
- 未定义的状态名 → 抛可读错误（中英双语），列出可用状态。

### 2.3 便捷单图动画

- 提供"按索引取帧 / 设置帧"的简单接口（单图策略下等价于换图）。

### 2.4 播放控制

| 接口 | 语义 |
|---|---|
| `play_anim()` | 开始 / 继续播放；**从当前帧继续**，不回到第 0 帧 |
| `pause_anim()` | 暂停，画面停在当前帧 |
| `stop_anim()` | 停止并**回到第 0 帧**（同时清零帧计时） |
| `is_anim_playing()` | 是否处于播放状态 |

- 新对象默认**就在播放**（建出来就会动）；想从头重播用 `stop_anim()` 再 `play_anim()`。
- 暂停只冻结帧推进，不影响其它任何东西：对象照常受物理、`goto()`、颜色/缩放/翻转影响，
  也照常绘制。
- 状态机暂停时**帧推进与状态切换一起冻结**，帧计时也不再累积：暂停期间赋的 `state`
  会在恢复播放后的那一帧生效（写状态仍是"下一帧生效"，见 §2.2）。
- 单图 / 整图策略没有帧序列：`frame` 恒为 0，播放状态照常读写（只是画面没有变化），不报错。
- 无视觉组件的对象调用这四个接口 → 一次性中英双语提示后中性返回（`is_anim_playing()` 为假）。

## 3. 绘制顺序

- 同一场景内按 `layer` 升序绘制；同一层按加入顺序。
- `move_to_front()` / `move_to_back()` 改到当前最前/最后；**本来就在最前/最后时保持不变**。
- 背景（`bgpic`）作为一个普通对象加入场景，可被 `kill()` 销毁，返回该对象便于后续操作。

## 4. 不变量

0. **每帧每个贴图只推进一次**（动画速度不受"谁在遍历"影响）；
   场景的绘制集合是唯一的每帧推进者。
1. 变换缓存只在标记为真时重算；一帧内对同一对象最多重算一次。
   角度**没变**时不标记重绘（物理层每帧回写角度是常态）。
2. `visible = False` 的对象不参与绘制，也不参与鼠标命中判定。
3. 颜色/透明度改动立即反映到下一次绘制（不需要等下一帧逻辑）。

## 5. 验收点

- 单图 / 帧序列 / 状态机 / 整图四种策略都能建出对象并渲染一帧不报错。
- 帧序列：`frame` 越界回环；`dt` 生效。
- 播放控制：`pause_anim()` 后帧不再推进；`play_anim()` 从当前帧继续；
  `stop_anim()` 回到第 0 帧且保持暂停；`is_anim_playing()` 如实反映状态；
  单图对象上调用这四个接口不报错。
- 状态机：`state` 赋值**下一帧**生效；不存在的状态名给可读错误。
- `set_dt`：帧序列 `set_dt(秒)` 生效；状态机 `set_dt(状态名, 秒)` 只影响该状态，
  另一个状态的 `dt` 不变；`set_dt(0)` / `set_dt("不存在的状态", …)` 都抛可读错误。
- 只改位置时图像不重算（用"重算计数"验证）；改颜色/缩放/旋转时重算一次后标记复位。
- 图层：`layer` 值大的画在上面；`move_to_front()` 后位于最上面。
